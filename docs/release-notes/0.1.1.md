# Satchel 0.1.1

Satchel now keeps itself up to date.

## Update by hand this once

Satchel 0.1.0 can't update itself, so install this version the way you installed 0.1.0: download the DMG below, open it and drag Satchel to Applications, replacing the old one. Your history and settings stay as they are. From now on, Satchel offers new versions itself.

## What's new

**Automatic updates**

- When a new version is out, the menu bar icon gets a small dot and its menu starts with **Update to Satchel …**. Nothing pops up and nothing interrupts you.
- Choose it to download the update, check its signature, install it and reopen Satchel. The menu shows the progress. You can also start it from the shelf or Settings.
- **Check for Updates…** in the menu bar checks whenever you like and tells you in a small window whether you have the newest version. Settings › Updates shows your version and when Satchel last checked.

**Acknowledgements**

- Settings › Acknowledgements… lists the open source software inside Satchel, with its licences.

## Privacy

- **Update checks are on by default.** When it starts and every 6 hours after, Satchel asks GitHub for the newest version. The request carries nothing about you, your Mac or your clips: no ID, no version number, no settings. GitHub sees your IP address.
- An update is downloaded only when you choose it, and installed only if it was signed with Satchel's own signing key.
- To turn the checks off: Settings › Updates, uncheck **Check for updates automatically**, then Save. Satchel then checks only when you ask. With link previews off too, Satchel makes no network requests on its own.

## Known limits

- macOS 11 or later on Apple silicon only.
- No sync between Macs.
